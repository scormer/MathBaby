Belief model

Capability Belief Tracing. Each capability has a hidden level (Not yet → Emerging → Developing → Secure → Consistent) and a probability for each level. Jev's P(true) is treated as soft evidence: the higher it is above the noise floor π, the more it shifts probability toward the higher levels. At or below π it does nothing, and it is never negative. Maturity = expected level ÷ 4. Between evidence events, a capability slowly drifts up (learning) and its confidence fades (staleness). Click any bar to see its level distribution or to set it by hand. Details: Capability_Belief_Model_Research.md.
